# pace-support

Support and privacy pages for the Pace iOS app.

## Files

- `index.md` -> Support page
- `privacy.md` -> Privacy Policy page

## Publish with GitHub Pages

1. Push this repo to GitHub as `pace-support`.
2. Go to **Settings -> Pages**.
3. Under **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Save and wait for Pages deployment.

## URLs

- Support URL: `https://northbound-labs.github.io/pace-support/`
- Privacy URL: `https://northbound-labs.github.io/pace-support/privacy`
